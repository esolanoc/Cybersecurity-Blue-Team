# 🧠 Memory, Pagefile & Hibernation

## 💾 Memory
- Memory is a device that stores data for **immediate use** in a computer.  
- Volatile: data is lost when the system powers off.  

---

## 🔍 Memory Analysis
- In forensics, this refers to the **analysis of volatile data** in a memory dump.  
- Helps investigators detect **running processes, connections, and malware activity**.  

---

## 📸 Memory Dump
- Snapshots captured moments before a **system crash or failure**.  
- Used to reconstruct the state of the system at that time.  

---

## 📂 Pagefile (Windows)
- Stores data from **RAM when it becomes full**.  
- Located in the root of the hard drive as `pagefile.sys`.  
- Forensics can extract **important evidence** from this file.  

---

## 🔄 Swapfile (Linux)
- Linux uses **swap space** to store RAM overflow.  
- Functions similarly to the Windows pagefile.  

---

## 💤 Hibernation (Windows)
- A Windows feature that saves the **current state of the system** when shutting down.  
- Stored in `hiberfil.sys`.  
- Forensics can analyze this file to recover **system state and user activity**.
