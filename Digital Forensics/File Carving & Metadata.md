# 💾 File Carving & Metadata

## 🗂️ File Carving
File carving is the process of **searching files within a data stream** to recover deleted files from disk images.  
This technique allows investigators to **analyze and reconstruct files** that have been removed but still leave traces on storage media.

- 🔍 Used in **digital forensics** to investigate deleted evidence.  
- 📂 Helps recover files without relying on file system structures.  
- 🛠️ Common tools: Autopsy, Sleuth Kit, Scalpel.  

---

## 🏷️ Metadata
Metadata is simply **“data about data”**.  
It provides context and information about a file, such as:

- 📅 **Date & time** of creation or modification.  
- 👤 **Author or owner** of the file.  
- 📍 **Location** or path where the file is stored.
