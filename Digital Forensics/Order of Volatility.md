# 🖥️ Infrastructure & Monitoring Components

## 💾 Cache and Register
- Temporary storage areas used by the CPU.  
- **Cache**: Stores frequently accessed data for faster retrieval.  
- **Registers**: Small, high-speed storage directly inside the processor.  

---

## 🧠 Memory (RAM)
- Random Access Memory used for **active processes**.  
- Provides fast read/write access for running applications.  
- Volatile: data is lost when the system powers off.  

---

## 💽 Storage (SSD / HDD)
- **SSD (Solid State Drive)**: Faster, uses flash memory.  
- **HDD (Hard Disk Drive)**: Mechanical, larger capacity but slower.  
- Stores operating system, applications, and user data.
