# 🖧 OSI Model (Open Systems Interconnection)

The **OSI model** was created by ISO in **1984** with the purpose of showing in detail how communication networks work, describing the different phases data needs to travel through.

---

## 📚 The 7 Layers

1. 🖥️ **Application Layer**  
   - Provides services directly to the user (e.g., HTTP, SMTP).

2. 🎨 **Presentation Layer**  
   - Translates, encrypts, and compresses data (syntax & semantics).

3. 🗂️ **Session Layer**  
   - Manages sessions and dialogues between applications.

4. 🚚 **Transport Layer**  
   - Ensures reliable delivery of data (TCP/UDP).

5. 🌍 **Network Layer**  
   - Handles logical addressing and routing (IP).

6. 🔗 **Data Link Layer**  
   - Provides error detection and frames data for transmission.

7. ⚡ **Physical Layer**  
   - Transmits raw bits over physical medium (cables, radio, fiber).
