# 🌐 Network Protocols Overview

## 🔹 TCP (Transmission Control Protocol)
- Used to allow systems to **establish a connection** with each other, enabling **two‑way communication**.  
- Works at the **Transport Layer**.  
- Part of the **TCP/IP protocol stack**, since TCP always relies on IP.  
- ✅ Reliable, ordered, and error‑checked delivery.  

---

## 🔹 UDP (User Datagram Protocol)
- Allows **datagrams to be sent without connection** in IP‑based networks.  
- 🚀 Faster but **unreliable** (no handshake, no guarantee of delivery).  
- Commonly used in **streaming, DNS, VoIP**.  

---

## 🔹 ICMP (Internet Control Message Protocol)
- Used to **diagnose network communication**.  
- Confirms if the **destination can be reached**.  
- 🛠️ Example: `ping` command.
