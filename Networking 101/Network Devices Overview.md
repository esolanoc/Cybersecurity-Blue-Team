# 🔧 Network Devices Overview

## 📡 Router
- Sends data using **logical addresses (IP)**.  
- Routes packets between **different networks**.  
- Example: Connecting a home network to the Internet.

---

## 🔀 Switch
- Similar to a hub, but smarter.  
- Uses the **MAC address** of the device to identify it.  
- Sends the frame only to the **intended recipient**.  

---

## 📢 Hub
- Broadcasts packets to **all devices** in the network.  
- ❌ Less efficient, since every device receives the same data.  

---

## 🔥 Firewall
- Blocks or allows traffic based on **security rules**.  
- Protects the network from **unauthorized access**.
