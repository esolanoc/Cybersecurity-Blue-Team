# 🖥️ Endpoint Security Tools

---

## 🛡️ Host Intrusion Detection Systems (HIDS)
Software instalado en un endpoint que detecta actividad sospechosa o maliciosa.  
Funciona con reglas que comparan la actividad contra patrones conocidos de ataque.  

---

## 🚫 Host Intrusion Prevention Systems (HIPS)
Similar al HIDS, pero además **previene** que la actividad maliciosa continúe.  
Las reglas incluyen acciones como:  
- ❌ Eliminar archivos  
- 🌐 Bloquear sitios web o IP  
- 🔔 Generar alertas  

---

## 🧩 Antivirus
Software instalado en dispositivos (PCs, servidores, endpoints) para detectar y eliminar malware.  
Tipos principales:  
- 📝 **Signature-based**  
- 🤖 **Behavior-based**
