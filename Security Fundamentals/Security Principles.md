# 🔐 Security Principles

These are security principles that ensure only allowed individuals are permitted access to IT resources.  

---

## 🪪 Authentication
Verification that confirms you are the individual.  
Example: logging into a bank website with a password only you know.  

**Types of Authentication:**  
- 🔑 **Something you have** → RFID card  
- 👤 **Something you are** → Biometric systems (fingerprint, Face ID)  
- 🧠 **Something you know** → PIN, password, security questions  

---

## 🛡️ Authorization
Defines what the user is permitted to do once authenticated.  

---

## 📜 Accountability
The process of identifying what has happened and when.  
This information can be used as evidence during a security event or incident.
